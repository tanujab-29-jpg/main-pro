# 🌌 Education Multiverse

An animated, interactive education and career exploration UI built for the UI Template Collection Hackathon.

## Core idea
Students explore multiple possible academic and career futures. Decisions change simulated compatibility scores, timelines, skill gaps and alternate realities.

## Included features
- Futuristic animated multiverse dashboard
- Career probability engine
- Interactive career planets and career detail modal
- Decision tree with branch exploration
- Career readiness score
- Skill Galaxy visualization
- Skill matrix and gap detector
- Future timeline
- Alternate reality generator
- What-if / scenario simulator
- Local saved realities using `localStorage`
- Responsive mobile sidebar
- Theme and sound controls
- Keyboard shortcut: `Ctrl/Cmd + K` opens the Multiverse Lab
- No framework or build step required

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- CSS animations
- Browser Local Storage
- Web Audio API for optional UI feedback

## Run
Open `index.html` in a modern browser. No server or installation is required.

## Research direction
The interface combines patterns commonly seen in modern dashboards, recommendation interfaces, data visualization, AI assistants, career planning products and simulation tools. Its differentiator is the "multiverse" metaphor: career paths are presented as interactive futures that users can compare and alter instead of as a static recommendation list.

## Important note
The career percentages are simulated UI values for exploration and demonstration. They are not predictions of a student's actual career outcome, salary, or employment probability.
